# private-data/

Local-only folder for real BSA / client files (seed JSON, spreadsheets, backups, headshots, renderings).

Everything in this folder except this README is **git-ignored**. Never move these files into `src/` or `public/`,
which are bundled into the public GitHub Pages build.

Import real files through the application's import screens (Stage 2+) on an approved machine.
Imported data lives in that browser's local storage only.
